# Kids Mini-Games Tizen App

A collection of classic arcade and puzzle mini-games built for children, specifically developed using **Tizen .NET (NUI)** and successfully tested on Samsung Tizen OS 9 hardware (Model: `GQ55Q60DAUXZG`).

## Description
This project bundles multiple interactive games into a single Tizen application designed for Samsung smart displays and TVs. Featuring a card reveal memory game, Snake, Tetris, and a Galaxy Shooter, it includes custom remote-control support, secret cheat-code navigation, and tailored profiles.

## Included Mini-Games
- **Card Reveal Memory Game:** Test your memory by matching pairs of cards.
- **Tetris:** Classic block-stacking puzzle action.
- **Snake:** Guide the snake to eat food and grow without hitting walls or itself.
- **Galaxy Shooter (Invaders):** Space arcade shooter action.

## Prerequisites
- **Visual Studio Code** installed.
- **Tizen .NET / Visual Studio Code Tizen Extension** configured.
- **Samsung Tizen TV / Device** (tested on Tizen OS 9, Model: `GQ55Q60DAUXZG`) with Developer Mode enabled.

## Build & Installation Guide

1. **Clone or Download the Project:**
   ```bash
   git clone [https://github.com/alanifotis/MemoryGame.git](https://github.com/alanifotis/MemoryGame.git)
   cd MemoryGame
   ```

`Open in VS Code:`

`Open the project folder inside Visual Studio Code where the Tizen extension is installed.`

`Build & Install via Tizen Extension:`

`Use the Tizen VS Code extension tools to build the package (.tpk).`

`Connect to your target Samsung device TV using its IP address via the Tizen Device Manager.`

`Run / Install the package directly to your TV.`
